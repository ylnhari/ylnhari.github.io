# ylnhari.github.io

Hari's personal portfolio site — live at **https://ylnhari.github.io/**. Production LLM/ML systems engineering: fine-tuning, serving at scale, and the projects behind it, plus a downloadable resume.

## Layout

- `index.html` — the site itself. A push to `main` deploys it via GitHub Pages.
- `resume/` — resume-related pages.
- `Hari_Yelesetty_Resume.pdf` — the downloadable resume.
- `assets/` — images and static files the site links to.
- `scripts/check_links.py` — fails if any internal link or asset path doesn't resolve to a real file. Run before publishing a change.

## Working on this site

See `AGENTS.md` for the full rules. In short: this is a public site, every content change is a publication, career facts are frozen unless Hari says otherwise, and nothing gets committed or pushed without his explicit ask.
